Before you play

  • Set your computer to a Japanese keyboard layout, so symbols land where this picture shows them. On Windows that is Settings › Time & language › Language; on a Mac, the Japanese input source.
  • Set your input to 英数 (direct / half-width alphanumeric) while you play. If keys do nothing, the Japanese input method is catching them.
  • Romaji mode is what you type when you write Japanese: ka gives か, kka gives っか. Every standard spelling is accepted.
  • Keys: Esc pauses, Backspace erases a wrong letter in romaji mode, Enter starts or restarts.
